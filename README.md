# mayorga-cueros-css

CSS del sitio de Mayorga Cueros (Tienda Nube).

`mayorga.css` es el archivo vivo: lo que está acá es lo que se ve en la tienda.
Se publica solo al hacer push. No hay que pegar nada en el panel.

Se carga desde el campo de codigo de seguimiento de Tienda Nube con una linea <link>.
